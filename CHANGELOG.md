# Changelog

## 0.2.0 — 2026-11-06

- Restored the final PRICAI R-series implementation and numerical analyses.
- Added the versioned measured-feature/result bundle, training/scoring entry points, and reproduction suites.
- Added pinned upstream versions, engine patches with separate license notices, and practical reproduction documentation.
- Rewrote the project README in English, Simplified Chinese, and Traditional Chinese.
- Preserved original measurements and documented differences in current-environment refits.

## 0.1.0 — 2026-11-06

First public code release accompanying GoTopoGuard (PRICAI 2026).

- Reference topology extraction for stone groups, distinct liberties,
  empty regions, edge reachability, and articulation points.
- Installable Python package, JSON command-line interface, and synthetic example.
- Feature definitions, expected output, regression tests, and CI.
- Apache-2.0 license and software citation metadata.

Trained scorers, guarded search, benchmark datasets, and complete paper
experiments remain outside this release.
