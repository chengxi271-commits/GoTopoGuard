# Data and models

**No external data or models are needed for v0.1.0.** The small board in
`examples/board.json` is a synthetic connectivity example, distributed with
the original code under Apache-2.0. It is not sampled from a benchmark game.

This repository does not redistribute KataGo, Leela Zero, ELF OpenGo,
neural-network weights, human game collections, engine self-play archives,
or adversarial game records. Upstream project links are listed in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Future paper-reproduction material will need exact engine/network versions,
source-data provenance, acquisition instructions, and applicable terms.
Downloading a current upstream model is not a substitute for the model used
in a historical experiment. Large raw logs and model files are not stored
in this repository's Git history.
